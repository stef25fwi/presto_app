## 🚀 DEPLOYMENT IN 30 MINUTES

### Step 1: Create Gmail App Password (5 min)
  → https://myaccount.google.com/apppasswords
  → Select: Mail + Your Device
  → Generate & Copy (16 chars)

### Step 2: Configure Environment (2 min)
  cd /workspaces/presto_app/functions
  cat > .env.local << 'EOF'
  GMAIL_USER=your-email@gmail.com
  GMAIL_PASSWORD=your-16-char-password
  EOF

### Step 3: Deploy Functions (3 min)
  cd /workspaces/presto_app
  chmod +x configure_params.sh
  ./configure_params.sh

### Step 4: Firebase Setup (5 min)
  → Create collection: admins
  → Add document: admins
  → Add field: admins (array of UIDs)

### Step 5: Security Rules (3 min)
  → Firebase Console → Firestore → Rules
  → Add: match /notifications/{docId} { ... }
  → Publish

### Step 6: Verify (5 min)
  firebase functions:list
  firebase functions:log --limit 50

### Step 7: Test Complete (10 min)
  → Publish offer (see orange badge)
  → Approve as admin (status: active)
  → Reject as admin (email sent ✓)
  → Verify on profile (warning visible)

## ⚠️ COMMON ISSUES

Issue: "GMAIL_USER is not set"
→ Deploy again: firebase deploy --only functions

Issue: "Permission denied"
→ Add your UID to admins collection

Issue: "Email not received"
→ Use App Password (not main password)
→ Check 2FA enabled
→ Check logs: firebase functions:log

Issue: "Badge doesn't appear"
→ Hot reload: Shift+R
→ Or restart app
→ Check status field in Firestore
