# Modèle du guide personnalisé iliprestō

## Objectif

Le PDF ne doit plus être une juxtaposition de blocs techniques. Il doit accompagner l’utilisateur depuis sa situation de départ jusqu’à sa première prestation, dans un ordre chronologique, avec des décisions vérifiables à chaque étape.

## Structure obligatoire du document

1. **Couverture personnalisée**
   - activité ;
   - région ;
   - statut actuel ;
   - titre : « Mon guide personnalisé pas à pas ».

2. **Situation et décision de départ**
   - résumé limité aux informations réellement saisies ;
   - niveau de vigilance ;
   - statut conseillé ;
   - justification courte ;
   - alternative ;
   - décision à confirmer.

3. **Points bloquants avant toute démarche**
   - uniquement les alertes qui peuvent modifier ou empêcher le projet ;
   - aucune répétition dans les étapes détaillées ;
   - formulation sous forme de checklist ;
   - l’utilisateur ne doit pas poursuivre avant validation.

4. **Feuille de route sur 30 jours**
   - regroupement par semaine ;
   - tâches dédupliquées ;
   - ordre chronologique ;
   - verbes d’action précis.

5. **Guide pas à pas**

   Ordre de référence :

   1. vérifier que l’activité peut être exercée ;
   2. sécuriser la situation personnelle et le cumul ;
   3. valider l’offre, les prix et le budget ;
   4. vérifier les aides avant la création ;
   5. choisir le cadre juridique, fiscal et social ;
   6. préparer le dossier ;
   7. déclarer l’activité ;
   8. mettre en place les assurances et documents commerciaux ;
   9. organiser la gestion et les échéances.

   Chaque étape doit contenir :

   - un objectif ;
   - des actions à cocher ;
   - les documents ou preuves à conserver lorsqu’ils sont connus ;
   - le résultat attendu avant de continuer.

6. **Modèles de courriers conditionnels**
   - salarié : demande de confirmation écrite à l’employeur ;
   - fonctionnaire : demande d’autorisation de cumul ;
   - demandeur d’emploi : demande de rendez-vous France Travail ;
   - assurance nécessaire : demande de devis professionnel.

7. **Sources officielles**
   - regroupées en fin de document ;
   - URL dédupliquées ;
   - aucune page composée uniquement de liens bruts ;
   - rappel de vérifier la date d’actualité de chaque règle.

8. **Checklist avant la première prestation**
   - autorisations obtenues ;
   - immatriculation disponible ;
   - assurance active ;
   - devis, facture et conditions prêts ;
   - suivi des recettes, dépenses et échéances en place.

## Règles anti-doublons

Une information ne doit apparaître qu’à son emplacement principal :

- les alertes dans « Points bloquants » ;
- les coûts dans l’étape budget ;
- les aides dans l’étape aides ;
- les règles liées au statut dans l’étape situation personnelle ;
- les sources dans l’annexe dédiée ;
- les obligations récurrentes dans l’étape gestion.

La génération doit normaliser la casse, la ponctuation et les espaces avant comparaison. Les listes séparées par des points-virgules ou des puces doivent être éclatées en actions distinctes avant déduplication.

## Règles de fiabilité métier

Avant publication d’une fiche :

- vérifier que l’activité, la famille métier, les codes APE, les assurances et les organismes sont cohérents ;
- interdire le mélange de blocs provenant d’une autre activité ;
- distinguer « activité réglementée », « activité libre avec obligations » et « information à confirmer » ;
- ne jamais présenter un code APE comme garanti : il reste indicatif jusqu’à attribution ;
- ne pas afficher une aide comme acquise : indiquer qu’elle dépend de conditions ;
- séparer les montants officiels datés des simples estimations ;
- faire apparaître la date ou la période de validité des seuils ;
- prévoir un audit automatisé des mots-clés incompatibles entre le nom de l’activité et son contenu.

## Critères d’acceptation

- document lisible sans connaissance juridique ou comptable ;
- ordre des démarches compréhensible sans revenir en arrière ;
- aucune répétition visible importante ;
- aucun mélange d’activité ;
- aucune section partiellement en anglais ;
- aucune page constituée uniquement de sources ;
- courriers présents uniquement lorsque la situation les justifie ;
- chaque étape se termine par un résultat attendu ;
- PDF valide sur une et plusieurs pages.
